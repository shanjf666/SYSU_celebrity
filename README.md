# 青春留名 · 第一版

中山大学红色人物档案馆网页。双击 `index.html` 或 `打开网页.bat` 即可在浏览器中打开，不需要安装任何软件或启动服务器。

## 文件夹说明

- `index.html`：主页面
- `people/`：6 位人物正文页
- `assets/`：页面样式、交互脚本、纸张纹理和人物占位影像
- `DESIGN.md`：第一版设计说明

## 使用提醒

- 页面中的人物文字与“影像待补”图片是框架样张，正式提交前仍需史料核对与照片替换。
- 封面需要点击朱砂印才会进入；右上角可以跳过开场。
- 建议使用 Edge 或 Chrome 打开。
- 所有文件需要保持当前相对位置，不能只单独发送 `index.html`。
