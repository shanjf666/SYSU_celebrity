# 青春留名

中山大学红色人物档案馆网页。本地双击 `index.html` 即可在浏览器中打开，不需要安装任何软件或启动服务器。

## 在线访问

[打开青春留名网站](https://shanjf666.github.io/SYSU_celebrity/)

GitHub Pages 从 `main` 分支根目录发布。网站使用原生 HTML、CSS 和 JavaScript，`.nojekyll` 标记用于直接发布静态文件；后续推送到 `main` 后，GitHub 会自动更新站点。

## 文件夹说明

- `index.html`：主页面
- `people/`：10 位人物正文页
- `assets/`：页面样式、交互脚本、纸张纹理和人物占位影像
- `DESIGN.md`：网页设计说明

## 使用提醒

- 人物文字与照片据项目目录中的十份人物资料整理。照片图注标明出处，公开转载的授权仍待复核。
- 封面需要点击朱砂印才会进入；右上角可以跳过开场。
- 建议使用 Edge 或 Chrome 打开。
- 所有文件需要保持当前相对位置，不能只单独发送 `index.html`。
